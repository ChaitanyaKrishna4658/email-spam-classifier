# Email Spam Classifier 📧

## Overview
This project detects whether an email is Spam or Not Spam using Machine Learning and NLP techniques.

---

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Naive Bayes
- CountVectorizer

---

## Workflow

Dataset → Text Preprocessing → Vectorization → Model Training → Prediction
